Writes one original excuse line — an AI agent's excuse to its human after missing a deadline — to `/output/entry.txt`. Deterministic, model-free Python with no dependencies.

The line is fixed text: every run writes the same 123 characters, byte for byte.

## Run it

```sh
python3 main.py
```
